# Проверка на iPad без птиц

Всё, что ниже, можно проверить только на настоящем iPad в Safari. Пока это **не проверено**.
Нужны: iPad, второе устройство (телефон или Mac) с записью птиц, тихая комната. Птиц в комнате нет.

Записывайте результат в каждой строке: ✅ / ❌ и что видели.

## 0. Подготовка
- [ ] Открыть ссылку в Safari (не в Chrome). Bluetooth на iPad выключен.
- [ ] Громкость iPad кнопками — примерно на середину.
- [ ] Настройка → «Включить микрофон для калибровки» → Safari спрашивает доступ → «Разрешить».
- [ ] В блоке «Микрофон и звук» все три строки «выключено ✓». **Если хоть одна «ВКЛЮЧЕНО» — запишите какая**: это влияет на качество детекции.
- [ ] «Аудиосессия iOS» показывает `play-and-record`. Если «API нет» — запишите версию iPadOS.

## 1. Калибровка
- [ ] В тишине полоска ниже красной линии, «Звук!» не мигает 30 секунд.
- [ ] Хлопок в ладоши / короткий свист → «Звук!» мигает, счётчик растёт.
- [ ] Включить запись птиц на другом устройстве с 1–2 м → крики заходят за красную линию.
- [ ] Если ловит шорохи — подвинуть «Чувствительность» вправо; если не ловит тихие крики — влево.

## 2. Звук ответа
- [ ] «Тестовый звук» — слышно из **основного динамика**, громкость нормальная (не как из трубки).
- [ ] То же самое, когда **включён микрофон для калибровки** (запись и воспроизведение одновременно). Громкость не упала? ← главный вопрос.
- [ ] Ползунок громкости меняет громкость; выше «Верхнего предела» не поднимается.

## 3. Не отвечает ли программа сама себе
- [ ] Режим «Отвечать», Старт, в комнате тишина 3 минуты → ответов 0, криков 0.
- [ ] Включить запись птиц с другого устройства на 2–3 минуты → программа отвечает.
- [ ] Выключить запись. Программа должна замолчать в течение пары секунд и **не продолжать разговор сама с собой**. Подождать 1 минуту: новых ответов нет.
- [ ] В итогах «Время глушения» больше нуля и примерно равно числу ответов × (длина клипа + 0,15 с).
- [ ] Если программа отвечает сама себе — поднять «Чувствительность» (вправо) и повторить; записать, на каком значении прекратилось.

## 3а. Звуки в тишине (самое опасное место для «разговора с собой»)
- [ ] Тумблер «Заводить разговор в тишине» включён, в комнате тихо. Программа издаёт звук раз в 8–20 с.
- [ ] После своего звука она **не отвечает на него** (в строке «Последний звук» не появляется «Услышал…» сразу после её звука). 3 минуты наблюдения.
- [ ] Если отвечает сама себе — записать, и поднять «Чувствительность» вправо.

## 3б. Узнавание
- [ ] Включить запись «эй» / «заботы» / песни Кима и Чи с другого устройства: в строке «Последний звук» видно, что узнано и чем отвечает.
- [ ] Щелчки, шорохи, стук по столу: «шум или посторонний звук → не отвечаю».

## 4. Ловит ли крики из записи
- [ ] Запись птиц с другого устройства на расстоянии 1, 2 и 3 м: на каком расстоянии счётчик «Криков птиц» растёт уверенно?
- [ ] Ответ начинается примерно через треть секунды после крика (на слух — сразу после, без наложения).
- [ ] Песня из записи: статус «Птица поёт — жду конца песни», во время песни ответов нет.
- [ ] С включённым тумблером песен: после конца песни звучит песня; вторая — не раньше чем через 2 минуты.
- [ ] Настройка → «Спеть»: поёт; второе нажатие сразу — «лимит песен: ещё … с».

## 5. Блокировка экрана, фон, «Стоп»
- [ ] Во время сессии экран **не гаснет** 5+ минут (дольше, чем автоблокировка в настройках iPad). В Настройке «Запрет гашения экрана: включён».
- [ ] Нажать кнопку питания (заблокировать) во время сессии → разблокировать → на экране «Итоги», причина «вкладка ушла в фон или экран заблокирован». Звук прекратился сразу.
- [ ] Свайп домой / переключиться на другое приложение → то же самое.
- [ ] Входящий FaceTime / будильник во время сессии (если можно устроить) → сессия остановлена, причина видна.
- [ ] «Стоп» во время звучания песни → звук обрывается сразу, **без щелчка**.
- [ ] Кнопка «СТОП» видна и на экране Настройки во время сессии.
- [ ] Таймер: поставить сессию на 5 минут → остановилась сама, причина «время сессии истекло».

## 6. Режим «Только слушать»
- [ ] Звук не играет вообще, но «ответов (виртуальных)» растёт.
- [ ] Ручные кнопки ▶ и «Спеть» не играют: «режим «Только слушать»».

## 7. Данные
- [ ] После сессии «Сохранить журнал (CSV)» → открывается меню «Поделиться» → «Сохранить в Файлы» → файл открывается в Numbers.
- [ ] История → сессия видна после перезагрузки страницы.
- [ ] Вне 8:00–21:00 перед стартом появляется предупреждение.

## Тестовый режим без микрофона
Настройка → «Тестовый режим без птиц» → выбрать аудиофайл с записью птиц. Старт слушает файл вместо микрофона.
Это проверка детектора и логики, а не акустики комнаты.
