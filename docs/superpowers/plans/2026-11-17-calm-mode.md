# Успокаивающий режим «Ким и Чи для меня» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Страница `calm.html`, которая тихо и живо чирикает клипами Кима и Чи для человека: одиночные чирики, пары, трели, паузы 10–20 с.

**Architecture:** Чистый планировщик без Web Audio (`app/js/calm-logic.js`) выдаёт «эпизоды» (одиночный / пара / трель) со всеми случайными параметрами; `app/js/calm.js` проигрывает их через Web Audio (выравнивание громкости, разброс, панорама, реверберация, общий регулятор) и рисует страницу. Приложение для птиц не меняется.

**Tech Stack:** Статический сайт, ES-модули, Web Audio API, `node --test` (как в проекте). Без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-17-calm-mode-design.md`

## Global Constraints

- Не менять `app/index.html`, `app/js/app.js`, `app/js/audio.js`, `app/js/logic.js`, `app/library.json`; в `app/css/app.css` только чтение (в нём чужие незакоммиченные правки).
- Не коммитить и не публиковать: владелец об этом не просил. Работа остаётся в рабочей копии.
- Пауза после любого «выхода» птиц: 10–20 с (после конца последнего звука); долгая тишина 40–90 с, шанс 0,05 вместо обычной паузы.
- Виды выходов: одиночный 0,55 / пара 0,25 / трель 0,20. Пара: второй чирик через 3–5 с после конца первого. Трель: 4–6 чириков (только крики), промежутки 0,25–0,9 с.
- Среди одиночных и вторых чириков пары: песни 0,25, крики 0,75.
- Не звучат категории «эй», «посмотрите на меня», «злость» (вес 0). «Забота» — вес 3 на каждый клип. Песни выбираются по категориям: «Ким» 1, «Чи» 1, «Ким и Чи» 0,5, «забота» 0,5, «без подписи» 0,5; неизвестная категория — вес 1.
- Один клип не повторяется, пока не прошло 8 других выборов той же группы (крики/песни); если выбрать не из чего — окно игнорируется.
- Разброс на каждый чирик: громкость ±3 дБ, высота (скорость) ±3 %. Ким левее (−0,35 ±0,1), Чи правее (+0,35 ±0,1), неизвестный — случайно −0,4…0,4.
- Громкость страницы: ползунок 0–100, старт 40, запоминается; кривая `(v/100)^1,5`; старт воспроизведения с плавным нарастанием за 2 с. На мастере — компрессор-ограничитель.
- Первый чирик через 2–6 с после нажатия «Играть».
- «Как часто»: реже ×1,6 / обычно ×1 / чаще ×0,6 на паузу.
- Версии `?v=` для CSS/JS страницы — `?v=1` (кеш Safari, см. README).
- Тексты интерфейса — по-русски, в стиле основного сайта (классы из `app.css`).

## Review Focus

- В библиотеке нет песен (или нет категории) → планировщик не падает, играют только крики.
- Клипов меньше, чем окно «без повторов» → всё равно возвращается клип, без бесконечного цикла.
- Незнакомая категория в библиотеке → звучит с весом 1.
- Громкость 0 → ровно тишина (`volumeToGain(0) === 0`), без NaN; 100 → 1.
- Тихий или «пустой» клип (rms 0) → усиление ограничено, не Infinity.
- Браузер без `audioSession`/`wakeLock` или с запрещённым `localStorage` → страница всё равно работает (проверка вручную в Task 2).

  - `volumeToGain(v: number) → number`.
  - `impulseResponse(sampleRate: number, seconds: number, rng?: () => number) → Float32Array` (шум с экспоненциальным затуханием).
